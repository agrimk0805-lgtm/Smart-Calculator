XIAO ESP32-S3 Advanced Multifunctional CalculatorAn open-source, feature-packed hardware calculator built using the Seeed Studio XIAO ESP32-S3, a 128x64 SSD1306 OLED Display, and a 4x4 Matrix Keypad. It includes security locking, real-time battery monitoring, financial modes, and an automated sleeping eye animation when idle.📌 Project SummaryThis project transforms a microcontroller into an all-in-one handheld calculator. Beyond standard arithmetic, it supports financial calculations like Compound Interest, Simple Interest, Profit & Loss, and GST / Tax adjustments. It also features PIN protection to restrict unauthorized access and an idle screensaver mode to conserve power.🎮 How to Use & Controls (Role Section)1. 🔒 Unlocking the DeviceWhen powered on, the calculator boots into a secure lock screen.Enter PIN: Use number keys (0–9) to type the PIN (Default PIN: 1388).Submit: Press * to verify.Delete / Clear: Press # to erase an incorrect digit.2. 🧮 Modes & NavigationThe calculator has 5 distinct modes. To switch between modes, use the SHIFT function:Press * to toggle [SHIFT] mode (indicated by [S] on top-left).Press * again while Shift is active to cycle to the next mode:[NORM] Standard Scientific Calculator[CI] Compound Interest Mode[SI] Simple Interest Mode[GST] GST & Discount Mode[P&L] Profit, Loss & Percentage Mode3.
